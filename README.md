# Tina Portfolio V2
Modern recruiter-focused redesign built with React + Vite.

## Run locally
1. `npm install`
2. `npm run dev`

## Build
`npm run build`

## Easy edits
- Resume-derived content: `src/data/portfolio.js`
- Layout/content: `src/App.jsx`
- Visual design: `src/styles.css`

This version intentionally does not depend on the old image assets, so it runs immediately. Add a portrait/project screenshots later if desired.
